# Power BI tutorial data

`Campaigns.csv` and `Calendar.csv` are the same fictional dataset the live demo
runs on, exported so a reader following the "recreate this template in Power BI
Desktop" tutorial has something real to import instead of building a model
from scratch. See the tutorial in the [full documentation](https://bi-report-template-site-documentation.readthedocs.io/)
for what to do with them.
